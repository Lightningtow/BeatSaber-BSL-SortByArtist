# BeatSaber-BSL-SortByArtist
Adds the ability to sort by the song's artist for BetterSongList

A huge thank you to SteffanDonal, author of [BeatSaber-BetterSongList-PlayCount](https://github.com/SteffanDonal/BeatSaber-BetterSongList-PlayCount), which I used as the basis for this mod.

Confirmed to work on Beat Saber 1.40.8 and 1.44.1, likely to continue working on future versions as long as BetterSongList doesn't get changed too much
