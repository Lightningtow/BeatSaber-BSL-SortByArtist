# BetterSongList-ArtistSort


Available on [BeatMods](https://beatmods.com/mods/432) and [GitHub](https://github.com/Lightningtow/BeatSaber-BSL-SortByArtist).

--------------------------
Adds the ability to sort by the song's artist inside [BetterSongList](https://github.com/kinsi55/BeatSaber_BetterSongList).

A huge thank you to [SteffanDonal](https://github.com/SteffanDonal/BeatSaber-BetterSongList-PlayCount), author of [BetterSongList PlayCount Sort](https://github.com/SteffanDonal/BeatSaber-BetterSongList-PlayCount), which I used as the basis for this mod.

Confirmed to work on the versions below. It is likely to work on other versions as long as BetterSongList's sorting mechanism doesn't get changed too much.  

Beat Saber 1.40.8 with BetterSongList 0.4.2  
Beat Saber 1.44.1 with BetterSongList 0.4.3  
           
        
           
### Easy Installation:
Download from within BSManager

### Manual Installation:
Download the DLL from GitHub and put it in the Plugins folder in your Beat Saber directory
